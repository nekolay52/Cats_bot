# 🐱 Telegram Cat Bot

Идеальный Telegram-бот для тех, кто без ума от котиков! Бот позволяет искать, сохранять, удалять и просматривать фото котиков с помощью удобных интерактивных слайдеров и кнопок.

---

## ✨ Основные возможности

* **🎲 Случайный котик:** Получи мгновенное фото случайного пушистика в один клик.

* **🖼️ Интерактивные слайдеры:** Листай галереи картинок прямо внутри Telegram с помощью Inline-кнопок.
! [Текст вместо картинки] (pictures/photo1.png)

* **📁 Управление списками:**
  * Создавай собственные списки любимых котиков.
  * Просматривай сохранённые коллекции.
  * Удаляй списки или отдельные картинки, если они больше не нужны.
! [Текст вместо картинки] (pictures/photo2.png)


---

## 🛠️ Технологии

* **Python 3.10+**
* **[aiogram 3.x](https://github.com/aiogram/aiogram)** — асинхронный фреймворк для Telegram Bot API.
* **Requests** — для получения фото через внешний Cat API.

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/nekolay52/Cats_bot
cd Cats_bot
```

### 2. Создать телеграм бота


С помощью `BotFather` создать бота и скопировать токен

### 3. Вы должены создать файл .env в папке проекта

```
TG_BOT_TOKEN= taken вашего Telegram бота
```

#### 4. Запуск программы осуществляется через `main.py`
